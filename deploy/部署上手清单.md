# MirrorU AI 官网重新上线 · 上手清单（阿里云轻量应用服务器 + 宝塔）

> 你的官网是**纯静态网站**（只有 HTML/CSS/JS，没有数据库和后台）。
> 本地源码已打包在 `mirroru-site.zip`，全部使用相对路径，传到任何服务器都能直接打开。

---

## ⚠️ 最重要的一步：先确认备案状态

国内节点（大陆）的服务器**必须 ICP 备案**，否则域名解析过去也打不开。

- 打开 **阿里云控制台 → 备案系统**，查 `liaoyiliaoai.com` 的备案状态。
- 若**已备案且接入方是阿里云**：同账号下换轻量服务器通常无需重新备案，但要在备案里更新服务器 IP / 接入信息。
- 若**备案已注销或在其他服务商**：需重新备案（约 1–2 周）或办理"接入备案"。
- **想跳过备案、立刻上线**：购买时把地域选 **中国香港 / 新加坡**，这些节点不需要备案即可直接访问（大陆访客速度略慢）。

---

## 第 1 步：购买轻量应用服务器

1. 阿里云官网 → **产品 → 轻量应用服务器（ECS 轻量）**。
2. **镜像**：选 **"宝塔 Linux 面板 9.x"**（有网页图形界面，最省心）。
   - 也可选 Ubuntu 22.04，之后自己装宝塔：`wget -O install.sh http://download.bt.cn/install/install_6.0.sh && sudo bash install.sh`
3. **地域**：大陆访客多选「华东/华南」；想免备案选「中国香港」。
4. **规格**：2 核 2G 足够（预算宽松选 2 核 4G）。
5. **带宽/流量**：3–5 Mbps 固定带宽，或按流量计费（网站流量很小，按量更省）。
6. 下单后记住 **公网 IP 地址**（后面解析域名要用）。

---

## 第 2 步：放行防火墙端口

在 **轻量应用服务器控制台 → 防火墙** 添加规则，放行：

| 端口 | 用途 |
|------|------|
| 22   | SSH（远程管理，默认已开） |
| 80   | HTTP 网站 |
| 443  | HTTPS 网站（配 SSL 用） |
| 8888 | 宝塔面板管理界面 |

---

## 第 3 步：登录宝塔并装 Nginx

1. 浏览器打开 `http://你的公网IP:8888`，用服务器创建时给的宝塔账号登录。
2. 首次进入会提示 **推荐安装**，勾选 **Nginx**（必装）；**MySQL / PHP 不需要**，可取消，然后一键安装。
3. 安装完成后进入宝塔主界面。

---

## 第 4 步：添加站点并上传网站文件

1. 宝塔左侧 **网站 → 添加站点**：
   - 域名：`liaoyiliaoai.com` 和 `www.liaoyiliaoai.com`（一行一个）
   - 根目录会自动生成 `/www/wwwroot/liaoyiliaoai.com`，保持默认
   - PHP 版本选「纯静态」即可
2. 进入该站点 → **根目录 → 上传**，把 `mirroru-site.zip` 传上去并**解压**，确保 `index.html`、`about.html`、`assets/` 等都在根目录里（若解压出二级文件夹，把里面的文件移出来）。
3. 删除宝塔默认生成的 `index.html`（被你的 `index.html` 覆盖即可）。

---

## 第 5 步：域名解析到新服务器

1. 到你**注册域名的地方**（阿里云域名控制台）进入 **DNS 解析**。
2. 添加两条 **A 记录**：
   - 主机记录 `@` → 记录值 `你的公网IP`
   - 主机记录 `www` → 记录值 `你的公网IP`
3. 等几分钟（最长几十分钟）生效。

---

## 第 6 步：配置免费 HTTPS（强烈建议）

1. 宝塔站点 → **SSL → 免费证书**（选 Let's Encrypt 或阿里云 DV 免费证书）。
2. 勾选 `liaoyiliaoai.com` 和 `www.liaoyiliaoai.com`，点击 **申请 / 部署**。
3. 打开 **"强制 HTTPS"** 开关。
4. 此时把 `liaoyiliaoai.com.conf` 里的 **443 块取消注释**、并确保证书路径正确，或在宝塔里直接保存即可（宝塔会自动写配置）。

---

## 第 7 步：验证上线

- 浏览器访问 `https://liaoyiliaoai.com`，应看到官网首页。
- 逐页点击：关于我们 / 产品 / 新闻 / 诚聘英才，确认图片和链接都正常。
- 微信里分享链接测试一下（HTTPS 下才能正常显示卡片）。

---

## 以后怎么更新网站？

改完本地 `xinyu-site/` 里的文件后：
- **小改动**：直接在宝塔「文件」里替换对应文件；或用 `mirroru-site.zip` 重新上传解压。
- **整站更新**：重新打包 `mirroru-site.zip`（已附脚本思路：zip 那 5 个 html + assets 即可），上传覆盖。
- 若走 CDN：在 CDN 后台刷新一次缓存即可立即生效。

---

## 附：备用方案（不想管服务器）

若你只想让网站先亮起来、不想运维，可继续用 **阿里云 OSS 静态托管 + CDN**：
把 `mirroru-site.zip` 解压内容上传到一个**公共读**的 OSS 存储桶，绑定 `liaoyiliaoai.com` 并开启静态网站托管，再用 CDN 加速。成本约几元–几十元/月，但本质仍是云存储，需保证存储桶和 CDN 不被误停。
